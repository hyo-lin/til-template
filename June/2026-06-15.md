### 새로 배운 내용
#### 주제 1: 네트워크, 노드
- 네트워크: 데이터를 송수신하는 기기들 간의 연결을 통해 정보와 자원을 공유할 수 있게 하는 시스템
  - 다양한 사용자와 기기 간에 정보를 공유하고, 하드웨어·소프트웨어 자원을 공동으로 활용하기 위해 사용됨
- Node: 네트워크에서 데이터를 생성, 수신, 또는 전송하는 장치나 지점
  - 노드는 컴퓨터, 서버, 라우터, 스위치, 프린터와 같은 다양한 형태로 존재할 수 있으며, 각 노드는 네트워크에서 고유한 주소(MAC 주소 또는 IP 주소)를 가지고 있습니다.

#### 주제 2: LAN, WLAN, VLAN, MAN, WAN, PAN
- LAN: 제한된 지역 내에서 컴퓨터나 기기들이 연결된 네트워크
  - 여러 기기가 자원을 공유하고, 내부 네트워크에서 빠르게 데이터를 전송하기 위해
- WLAN: 무선 기술을 사용하여 장치들이 서로 연결된 네트워크
  - 케이블 없이 자유롭게 네트워크에 연결하기 위해 사용됨
- VLAN: 물리적 네트워크를 논리적으로 분리하여 여러 개의 독립된 네트워크처럼 사용할 수 있게 하는 기술
- MAN: 도시나 여러 건물을 연결하는 네트워크
- WAN: 광범위한 지역을 연결하여 데이터 통신을 가능하게 하는 네트워크
- PAN: 개인 주변의 장치들을 연결하여 통신을 가능하게 하는 네트워크
- LAN<MAN<WAN

#### 주제 3: NIC, MAC address, 리피터, 게이트웨이, 라우터, 허브, 스위치, 브릿지
- NIC: 컴퓨터, 서버, 또는 기타 네트워크 장치가 네트워크에 연결되도록 해주는 하드웨어 구성 요소
  - 컴퓨터가 네트워크에 연결되어 데이터를 송수신하며 통신할 수 있도록 하기 위해
- 가상 NIC: 가상 머신(Virtual Machine) 또는 컨테이너가 물리적 NIC 없이 네트워크에 연결되도록 지원하는 소프트웨어 기반의 네트워크 인터페이스
- MAC Control Address: 네트워크 장치의 물리적 주소를 나타내는 고유 식별자
  - 네트워크 내에서 장치를 식별하고, 통신할 때 데이터를 원하는 장치로 전달하기 위해 사용됨
  - Mac Spoofing: 장치의 원래 MAC 주소를 변경하여 네트워크에서 다른 장치인 것처럼 속이는 기술
    - 1. 네트워크 인터페이스 카드(NIC)는 소프트웨어 설정을 통해 원래 MAC 주소를 변경할 수 있는 옵션을 제공합니다.
    - 2. 사용자 또는 프로그램은 임의의 MAC 주소를 설정하여 네트워크에서 장치를 인식시키는 MAC 주소를 조작합니다.
- Repeater: 네트워크에서 신호를 증폭하거나 재생하여 더 먼 거리로 전달하는 장치
  - TCP/IP 네트워크 액세스 계층에서 활용되며, 물리 계층에서 작동합니다.
  - 신호의 감쇠를 방지하고, 네트워크의 범위를 확장하기 위해 사용합니다.
- Gateway: 서로 다른 네트워크를 연결하여 통신을 가능하게 하는 장치
  - 서로 다른 네트워크를 연결하고, 네트워크 간의 데이터 전송과 프로토콜 변환을 담당
  - 서로 다른 네트워크 간의 데이터 전송 및 프로토콜 변환을 위해 사용됩니다.
- Router: 두 개 이상의 네트워크를 연결하고, 데이터 패킷이 올바른 경로를 통해 목적지에 도달하도록 관리하는 네트워크 장치
  - IP 주소를 기반으로 데이터를 라우팅하며, 특히 LAN(근거리 통신망)과 WAN(광역 통신망) 간의 연결을 관리할 때 중요합니다.

- 네트워크 장비인 게이트웨이와 라우터의 핵심 차이점을 정리한 비교 표입니다.
- | 특징 | 게이트웨이 (Gateway) | 라우터 (Router) |
  | :--- | :--- | :--- |
  | **주요 기능** | 프로토콜 변환, 데이터 필터링, IP 변환 | IP 주소 기반 데이터 경로 설정 및 라우팅 |
  | **동작 계층** | 애플리케이션 계층 (Application Layer) | 인터넷 계층 (Internet / Network Layer) |
  | **처리 데이터** | 서로 다른 네트워크나 프로토콜 간 데이터 | 동일한 프로토콜을 사용하는 네트워크 간 데이터 |
  | **사용 목적** | 네트워크 간 데이터 변환 및 전송 | 데이터 패킷을 최적 경로로 전달 |
  | **위치** | 네트워크 경계 (서로 다른 네트워크 연결 지점) | 네트워크 내 또는 네트워크 간 |
  | **예시** | VoIP 게이트웨이, IoT 게이트웨이 | 가정용 무선 라우터, 기업용 코어 라우터 |

- Hub: 네트워크에서 데이터를 여러 장치로 전달하는 장치
  - 각 장치로부터 데이터를 수신하고, 수신된 데이터를 네트워크에 연결된 모든 다른 장치로 전송합니다.
  - 허브는 모든 장치에 데이터를 동시에 보내는 방식으로 작동합니다. 이 때문에 소규모 네트워크에서 설치와 관리가 간편하고 비용이 저렴해 단순한 내부 네트워크 연결용으로 많이 사용됩니다.
  - 하지만, 이 때문에 네트워크 트래픽이 많아지면 충돌(Collision)이 발생할 가능성이 높아집니다.
- Switch: 네트워크 내에서 데이터 패킷을 장치 간에 전달하는 네트워크 장치
  - 데이터를 목적지 장치로 정확하게 전달하는 기능을 수행하며, 각 장치의 MAC 주소를 기반으로 데이터를 전송합니다.
  - 네트워크 내에서 데이터 패킷을 정확하게 전달하기 위해 사용됩니다.
- Bridge: 네트워크에서 두 개 이상의 LAN을 연결하는 장치
  - 두 개의 네트워크를 연결하여 데이터 통신을 가능하게 하기 위해 사용됨
  
- | 장치명 | 주요 계층 | 기본 동작 / 역할 | 특징 |
  | :--- | :--- | :--- | :--- |
  | **허브 (Hub)** | 데이터 링크 계층<br>*(실제로는 물리 계층에 가까움, L1~L2)* | • 연결된 모든 포트로 데이터를 무차별 전송 (브로드캐스팅)<br>• MAC 주소를 인식·학습하지 않음 | • 대역폭 낭비가 크고, 소규모 네트워크에서만 사용 권장<br>• 최근에는 사용량이 점차 줄어드는 추세 |
  | **스위치 (Switch)** | 데이터 링크 계층<br>*(Layer 2)* | • 장치의 MAC 주소를 학습한 후 특정 대상(포트)에만 데이터 전송 | • 허브보다 지능적이며, 트래픽 효율성이 높음<br>• L3 스위치의 경우 라우팅 기능까지 포함 가능<br>• 주로 LAN 환경에서 사용 |
  | **라우터 (Router)** | 네트워크 계층<br>*(Layer 3)* | • IP 주소 기반으로 패킷의 경로를 선택(라우팅)<br>• 내부망 ↔ 외부망 연결 및 관리 담당 | • WAN/LAN 간 데이터 전달을 담당하며 최적의 경로를 찾아 패킷을 전달<br>• 게이트웨이 역할을 수행하며, 인터넷 접속 시 필수적인 장치 |
  | **브릿지 (Bridge)** | 데이터 링크 계층<br>*(Layer 2)* | • 두 개의 LAN 세그먼트를 연결하여 동일 네트워크처럼 동작하도록 중계<br>• MAC 주소 기반으로 프레임 전달 | • 주로 소규모 LAN 확장이나 세분화에 사용<br>• 다른 네트워크를 연결하는 라우팅 기능은 없음 |
  | **게이트웨이 (Gateway)** | 네트워크·전송·응용 계층 등<br>*(Layer 3 이상)* | • 서로 다른 프로토콜 및 네트워크 간의 프로토콜 변환 (로컬망 ↔ 인터넷 연결 등) | • 라우터·방화벽·프록시 등 다양한 기능을 통합하여 수행<br>• 외부 네트워크와 통신 시 필수적이며, L4~L7 계층 기능을 포함하는 사례도 많음 |

- OSI 7계층 모델 (OSI 7-Layer Model)
  - | 계층 | 계층명 (Layer) | 역할 및 설명 |
    | :--- | :--- | :--- |
    | **7계층 (L7)** | **Application Layer** *(응용)* | 사용자와 애플리케이션 간의 직접적인 인터페이스 제공 (HTTP, FTP 등) |
    | **6계층 (L6)** | **Presentation Layer** *(표현)* | 데이터의 포맷 변환, 인코딩/디코딩, 암호화 및 압축 수행 |
    | **5계층 (L5)** | **Session Layer** *(세션)* | 양 끝단의 응용 프로세스 간 통신을 위한 세션 설정, 유지, 관리 및 종료 |
    | **4계층 (L4)** | **Transport Layer** *(전송)* | 종단간(End-to-End) 신뢰성 있고 정확한 데이터 전달 보장 (오류/흐름 제어) |
    | **3계층 (L3)** | **Network Layer** *(네트워크)* | 패킷의 최적 데이터 경로 설정 및 라우팅(IP 주소 기반) 수행 |
    | **2계층 (L2)** | **Data Link Layer** *(데이터 링크)* | 물리적인 링크를 통한 인접 장치 간 데이터 전송 오류 제어 및 흐름 관리 |
    | **1계층 (L1)** | **Physical Layer** *(물리)* | 전선, 광케이블 등 물리적 매체를 통한 비트(Bit) 단위의 실제 데이터 전송 |

- TCP/IP 4계층 모델 (TCP/IP 4-Layer Model)
  - | 계층 | 계층명 (Layer) | 역할 및 설명 |
    | :--- | :--- | :--- |
    | **4계층 (L4)** | **응용 계층** *(Application)* | OSI의 5~7계층을 통합한 영역으로, 사용자 서비스 및 애플리케이션 프로세스 제공 |
    | **3계층 (L3)** | **전송 계층** *(Transport)* | OSI 4계층에 대응되며, 프로세스 간 데이터 전송 및 신뢰성 보장 (TCP/UDP) |
    | **2계층 (L2)** | **인터넷 계층** *(Internet)* | OSI 3계층에 대응되며, 패킷 전달 및 네트워크 간 최적의 경로 설정 (IP) |
    | **1계층 (L1)** | **네트워크 액세스 계층** *(Network Access)* | OSI 1~2계층을 통합하여 실제 물리적인 네트워크 연결 및 프레임 전송 처리 |
